# lyrnox

## sb.sh — sing-box 一键安装（VLESS-Reality，443 端口）

```bash
bash sb.sh
```

需 root 运行。每天北京时间 05:00 自动检查并更新 sing-box（失败自动回滚），最后打印 v2rayN 链接。再次运行 = 卸载重装，密钥全部重新生成。
可选环境变量：`SNI=域名` `SERVER_IP=公网IP` `SB_VERSION=1.x.y`

## vps_tools.sh — VPS 工具箱（交互菜单）

```bash
bash vps_tools.sh
```

含系统更新、DD 系统、八合一节点工具箱、改 DNS、压力测试、性能测试、装 Docker/1Panel/哪吒面板等，需 root 运行。
